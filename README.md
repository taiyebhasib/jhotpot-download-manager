ঝটপট ডাউনলোড ম্যানেজার (JDM) হলো উইন্ডোজের জন্য তৈরি উচ্চগতির সেগমেন্টেড মাল্টি-থ্রেডেড 
ডাউনলোড ম্যানেজার।

বিশেষ সুবিধাসমূহ:
- ইউটিউব ও ফেসবুক ভিডিও ডাউনলোডার (সকল রেজোলিউশন ও সরাসরি MP3 কনভার্ট সুবিধা)
- বিল্ট-ইন হাই-স্পিড বিটটরেন্ট (BitTorrent) ইঞ্জিন (অন্য কোনো ক্লায়েন্ট ছাড়াই)
- আইডিএম (IDM) স্টাইল অটোমেটেড ডাউনলোড শিডিউলার (Queue Scheduler)
- ইন-প্লেস অটো-আপগ্রেড ও সিঙ্গেল-ইনস্ট্যান্স ট্রে এক্সিকিউশন
- ক্রোম, এজ, ব্রেভ, অপেরা এবং ফায়ারফক্স ব্রাউজারের সাথে ১-ক্লিকে ইন্টিগ্রেশন
- রাইট-ক্লিক "Download with JDM" কনটেক্সট মেনু (ছবি, লিংক, ভিডিও ও পেজ সরাসরি ডাউনলোড)

ইনস্টলেশন ও ব্রাউজার এক্সটেনশন সেটআপ নির্দেশিকা (Step-by-Step Guide):
--------------------------------------------------------------------------------

================================================================================
ধাপ ১: সফটওয়্যার ইনস্টল করা
================================================================================
১. "Jhotpot_Download_Manager_Setup.exe" ফাইলটিতে ডাবল-ক্লিক করে সেটআপ রান করুন।
২. ইনস্টলারটি সম্পূর্ণ স্বয়ংসম্পূর্ণ (Self-contained)। এর ভেতরে yt-dlp, ffmpeg, 
   নেটিভ মেসেজিং হোস্ট এবং ব্রাউজার এক্সটেনশন সম্পূর্ণ বিল্ট-ইন রয়েছে। 
   আলাদা কোনো yt-dlp বা ffmpeg ইনস্টল করতে হবে না।
৩. ইনস্টলারটি পূর্ববর্তী যেকোনো রানিং ইনস্ট্যান্স স্বয়ংক্রিয়ভাবে বন্ধ করে নিরাপদে 
   ইনস্টল বা আপগ্রেড সম্পন্ন করবে এবং আপনার সেটিংস ও হিস্টোরি সুরক্ষিত রাখবে।
৪. ইনস্টলেশন শেষে ঝটপট ডাউনলোড ম্যানেজার স্বয়ংক্রিয়ভাবে চালু হবে।

================================================================================
ধাপ ২ (ক): Chrome / Edge / Brave / Opera ব্রাউজারে এক্সটেনশন যোগ করা
================================================================================
১. JDM সফটওয়্যারটি খুলে বাম পাশের গিয়ার আইকন (Settings / Preferences) -> 
   Browser Integration ট্যাবে যান।
২. "Open Chromium Extension" বাটনে ক্লিক করুন। সাথে সাথে উইন্ডোজ ফাইল এক্সপ্লোরারে 
   "browser-extension" ফোল্ডারটি হাইলাইট (সিলেক্ট) অবস্থায় দেখতে পাবেন।
৩. আপনার ব্রাউজারে যান:
   - Google Chrome: chrome://extensions
   - Microsoft Edge: edge://extensions
   - Brave: brave://extensions
   - Opera: opera://extensions
৪. ব্রাউজারের উপরে ডান কোণে থাকা "Developer mode" টগলটি চালু (ON) করুন।
৫. এবার উপরে বাম পাশের "Load unpacked" বাটনে ক্লিক করুন।
৬. ফাইল ডায়ালগে সরাসরি হাইলাইট হওয়া "browser-extension" ফোল্ডারটি সিলেক্ট করুন।
   (★ সতর্কতা: ফোল্ডারের ভেতরে ঢুকে "icons" ফোল্ডার সিলেক্ট করবেন না; সরাসরি 
    মূল "browser-extension" ফোল্ডারটি সিলেক্ট করবেন)।
৭. এক্সটেনশনটি যোগ করার সাথে সাথেই তা স্বয়ংক্রিয়ভাবে JDM-এর সাথে কানেক্ট হয়ে যাবে! 
   কারণ এতে পার্মানেন্ট ফিক্সড আইডি (Fixed ID: gpkjhikpaikkjdafldkjkkilnaklofam) যুক্ত রয়েছে, 
   তাই কোনো আইডি ম্যানুয়ালি কপি বা পেস্ট করারও প্রয়োজন নেই।
   (প্রয়োজনে JDM Settings-এর Browser Integration থেকে যেকোনো সময় 
    "Install Browser Extension Host" বাটনে ক্লিক করে হোস্ট রিফ্রেশ করে নিতে পারেন)।
৮. ব্রাউজারটি পুরোপুরি বন্ধ করে আবার চালু করুন।

================================================================================
ধাপ ২ (খ): Mozilla Firefox ব্রাউজারে এক্সটেনশন যোগ করা
================================================================================
১. JDM-এর Settings -> Browser Integration থেকে "Open Firefox Extension" বাটনে ক্লিক করুন। 
   উইন্ডোজ এক্সপ্লোরারে "browser-extension-firefox" ফোল্ডারটি সিলেক্টেড অবস্থায় দেখতে পাবেন।
২. Firefox ব্রাউজারে নতুন ট্যাবে about:debugging#/runtime/this-firefox লিখে Enter চাপুন।
৩. "Load Temporary Add-on..." বাটনে ক্লিক করুন।
৪. "browser-extension-firefox" ফোল্ডারের ভেতরে গিয়ে "manifest.json" ফাইলটি সিলেক্ট করুন।
   (নোট: ফায়ারফক্স সাধারণ ভার্সনে প্রতি সেশনের জন্য সাময়িক অ্যাড-অন হিসেবে লোড করে; 
    স্থায়ীভাবে রাখতে চাইলে Firefox Developer Edition বা Nightly ব্যবহার করতে পারেন)।
৫. JDM-এর Settings থেকে "Install Browser Extension Host" বাটনে ক্লিক করা নিশ্চিত করুন।
৬. Firefox ব্রাউজার রিস্টার্ট করুন।

================================================================================
ধাপ ৩: ব্যবহার ও ডাউনলোড পরীক্ষা (How to Test & Use)
================================================================================
১. সাধারণ ফাইল স্বয়ংক্রিয় ডাউনলোড:
   ইন্টারনেট থেকে যেকোনো ফাইল (.zip, .rar, .iso, .exe, .torrent ইত্যাদি) ডাউনলোডে ক্লিক করলেই 
   ব্রাউজারের ধীরগতির সিঙ্গেল-কানেকশন ডাউনলোডের বদলে JDM স্বয়ংক্রিয়ভাবে ইন্টারসেপ্ট করে 
   উচ্চগতির মাল্টি-কানেকশন উইন্ডো ওপেন করবে।

২. যেকোনো ছবি, লিংক বা পেজ রাইট-ক্লিক ডাউনলোড:
   ব্রাউজারে যেকোনো ছবি, ভিডিও, লিংক বা পেজের ওপর মাউসের রাইট-ক্লিক করে "Download with JDM" 
   সিলেক্ট করলেই সাইজ নির্বিশেষে (যেকোনো ছোট ছবি বা বড় ফাইল) সরাসরি ঝটপট ডাউনলোড ম্যানেজারে 
   ডাউনলোড শুরু হবে।

৩. ভিডিও ও গান ডাউনলোড (YouTube / Facebook / Web Streams):
   - যেকোনো YouTube ভিডিও/শর্টস, Facebook রিল/ভিডিও বা ওয়েব স্ট্রিমিং মিডিয়া পেজ চালু করুন।
   - ব্রাউজার টুলবারে থাকা JDM এক্সটেনশন আইকনে ক্লিক করুন।
   - পপআপ কার্ডে থাকা "Download Video / MP3 in JDM" বাটনে ক্লিক করুন 
     (অথবা নিচে ডিটেক্ট হওয়া HLS .m3u8 বা DASH .mpd স্ট্রিম সিলেক্ট করুন)।
   - JDM সাথে সাথে ভিডিওর সকল রেজোলিউশন (4K, 1080p, 720p ইত্যাদি) ও MP3 অপশন নিয়ে হাজির হবে!
